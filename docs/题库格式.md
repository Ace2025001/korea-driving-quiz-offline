# 题库 JSON 1.0

应用使用与浏览器相同的严格运行时校验器 [src/core.js](../src/core.js)。字符内容以纯文本显示。未知字段不参与导入。正式模拟只使用与内置的官方原件指纹清单相符、已生效、所需素材也通过核对的题目。

| 字段 | 约束 |
| --- | --- |
| schema_version | 字符串 `1.0` |
| bank_version / effective_date | 版本 ID；有效的 `YYYY-MM-DD` 日期。生效以韩国当地日历为准 |
| source_url / attachment_sha256 | HTTPS 来源（自备题库可留空）；官方 PDF 小写 SHA-256 |
| questions | 1–5000 条，题号不可重复 |
| question_id / question_type / prompt_zh | 唯一 ID；`single` 或 `multiple`；非空题干 |
| options | 2–10 个 `{id,text}`，ID 唯一 |
| correct_answers | 每项均引用存在的选项 ID，不重复。单选恰好一个，多选至少两个 |
| points | 1–100 的整数或者 `null`。当前版本不按此字段计算官方成绩 |
| media_kind / image_asset / video_asset | `none`、`image`、`video`；素材是内嵌 base64 data URL 或 `null`。图片 PNG/JPEG/WebP，视频 MP4/WebM。声明缺素材的题默认不出现在练习中 |
| legal_refs / trap_tags / topics | `[{label,url}]`，地址 HTTPS；标签与专题是无重复的字符串数组 |
| explanation_zh | 字符串，可留空；附带规则提示应标明为关联考点 |
| official_explanation_ko | 可选韩文原文，只有独立匹配官方韩文原件指纹才标作官方解析 |
| verification_status / copyright_status | `verified` / `pending`；`personal_only` / `unverified` / `redistributable`。均为声明；不能用这些字段自行宣称官方核验或公开许可 |
| evidence | `null` 或 `{page,method,ko_page?}`。PDF 页码从 1 开始 |

### 校验和隔离

内置清单来自固定 SHA-256 的官方附件。应用重新计算每题的题号、题型、题文、选项、答案、原件页码和素材类型的 SHA-256，再与清单比对；素材单独对解码后的字节比对。题目核验表示与官方印刷答案一致，**并非独立判定每个法律结论或翻译**。自带分值不影响模拟。

学习记录以版本和官方 PDF 指纹为键。未核验内容以其数据指纹隔离。同版官方题库重新导入会合并已经校验的题目和素材，两个不同版本不会合并。完整备份恢复会替换当前学习记录，恢复前先导出当前记录以备回退。
